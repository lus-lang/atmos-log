# Changelog

## 1.0.0

**Release date:** TBD

Version 1.0.0 is the first release of `log`.

- Added the `log` package.
  - `log.new`: Creates a logger that writes JSON lines at and above a level.
  - `log.pretty`: Formats one JSON line for a terminal.
  - `log.register`: Registers the request log on a `web` scope.
  - `log.levels`: Holds the numeric value of each level name.
